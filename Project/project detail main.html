Challenge

Distill a sprawling operations dataset into a single, calm screen — one that surfaces the shipments that need attention first, without turning the interface into a warehouse of reports and figures.

What we did
  • Redesigned the core tracking workspace around live shipment status
  • Built a risk-first triage model dispatchers actually trust
  • Designed the responsive system used across web, tablet and mobile
  • Ran usability sessions with dispatch teams across three release cycles
  • Shipped the rollout documentation and onboarding flows
